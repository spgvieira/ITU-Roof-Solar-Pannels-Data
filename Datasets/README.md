# Datasets

The following datasets are available:
1. `PV.csv` - hourly average power generated by solar pannels (or energy), measure in W, from 15/10/2025 to 15/09/2026
2. `ECMWF_forecast.csv`:
    * Forecast data from 15/10/2025 to 03/10/2026 
    * ECMWF IFS HRES 9km model
    * all different latitude longitude values have the same results (too small resolution)
3. `DMI_august_forecast.csv`: 
    * Forecast data for the entire month of august 2026
    * DMI Harmonie AROME Europe
    * every coordinate pair has different results
